Lunssi is a website displaying lunch menus near the Helsinki and Tampere centrums. The list of supported restaurants is ever expanding. Visit https://lunssi.fi.

Feel free to propose new restaurants or contact us for anything else at contact@lunssi.fi.

## Installation

- Install [Task](https://taskfile.dev/installation/)
- Initialize project with `task init`. This command installs all necessary
  dependencies for both the frontend and backend. It also creates a Python
  virtual environment for the backend to manage its dependencies.

## Frontend

The frontend is built with Next.js and is exported as a static site (no
Node.js server in production).

### Starting the frontend

Start a development server with `task dev:frontend`. The server runs on port 3000.
It reads restaurant data from `frontend/data/*.json`, which is generated by
the backend scrapers — run `task dev:data` (or just `task dev`, which does
both) first if that directory doesn't exist yet.

### Deploy to Cloudflare Pages

Deployment is fully automated via GitHub Actions
(`.github/workflows/build-and-deploy.yml`), which runs once a day, on every
push to `main`, and on manual dispatch. It scrapes fresh menu data, builds
the static export, and deploys it to the `lunssi` Cloudflare Pages project
using `wrangler`.

To deploy manually instead:

```sh
cd frontend
npm run build
npx wrangler pages deploy out --project-name=lunssi
```

Run `npx wrangler pages deploy` from the `frontend/` directory or the repo
root, not from inside a directory Wrangler might mistake for a full Next.js
app it should migrate to Workers — it will otherwise try to rewrite
`package.json`/`next.config.ts` to set up server-side rendering, which this
project doesn't use.

## Backend

The backend of the application is built with Python. There is no
always-on server — `backend/generate_static_data.py` runs the scrapers
once and writes their output to `frontend/data/*.json`, which the frontend
reads at build time. This runs automatically in CI once a day.

### Starting the backend

Run `task dev:data` to (re)generate `frontend/data/*.json` locally.

`task dev:backend` also starts a small FastAPI server on port 8080 for
interactively testing a single scraper (e.g.
`curl 'http://localhost:8080/restaurant?name=hamis'`) — it is not deployed
anywhere.
